Admission Prediction using Artificial Neural Network (ANN)

This project predicts a student's chance of admission into a university using an Artificial Neural Network (ANN) built with TensorFlow and Keras.

The model learns patterns from student academic records such as GRE score, TOEFL score, CGPA, SOP, LOR, and research experience to estimate admission probability.
